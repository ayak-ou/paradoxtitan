# ParadoxTitan: F1 Race Simulation

First-year project at ENSICAEN, written in C by a team of two.


## Approach
- A* pathfinding algorithm with a Fibonacci heap, used to optimise
  the speed and fuel coefficients of the car
- Result: 7 races won out of 12 against other cars



## Project structure
- `src/`: source code
- `include/`: header files
- `docs/`: project report and presentation (PDF)
- `Makefile`: build instructions
